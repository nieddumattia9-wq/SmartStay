## Operational invocation

Use the existing `scripts/invoke-liteapi-search-coverage.ps1`, invoked through
`powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File`, not by directly
executing the ps1 under the user's default policy. Bypass applies only to that
child process. Inventory and Preflight are credential-free and do not create
real custody. Preflight probes CurrentUser DPAPI with invented bytes in memory.

On a separately authorized Acquire, the launcher first displays and requests
the exact literal, then calls `Read-Host -AsSecureString` for the key. Never put
the key in a command, file, environment or conversation. The final handoff must
bind explicit file SHA-256 hashes and the exact published HEAD. The literal uses
canonical configuration/inventory hashes: copy the actual generated value,
not a manually reconstructed substitute.

Check that the result file is absent before launch. Read the output afterward
even when the process exits zero: a controlled ABORTED result is not COMPLETE.
Two attempts can be valid with an empty catalog; otherwise at most three. Never
remove markers, reuse consumed authorization, retry or restart after interruption.
