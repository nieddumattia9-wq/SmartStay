## Problem and decision

Three reproduced defects in the new evaluation boundary allowed callers to
remove essential checks through consistent false flags, send inapplicable price
or distance values to the actual bridge, and turn `Two guests` into a false
zero-capacity violation despite intact source hashes. Passing D-0051 tests was
not proof against these failures. The original six synthetic observations and
20-failure expanded test run are preserved, not rewritten.

Coverage must be derived from original essential needs: recognize only supported
wording, verify the complete mapping and expose unrepresented essential needs as
unevaluated blockers. Do not create unrequested privacy. KNOWN does not establish
applicability: selected-rate totals require offer scope; spatial/rating facts may
use an explicitly evidenced property-to-offer link. Preserve partial diagnostics,
but never pass inapplicable values as recommendation facts. Recompute bounded
capacity/unit/internal-room/child-policy transformations from the actual reviewed
field; unsupported text remains uncertain. Do not create a universal interpreter.

## Safeguards and consequences

R1 uses contract versions @1.1 / @2.1 and rejects implicit old-document migration.
D-0050 and original D-0051 reports/results remain intact; no real review or private
evaluation is repeated. The complete supported synthetic input remains unchanged
through the existing bridge. Family composition, suite units, sofa/bunk UNKNOWNs,
observed availability and complete-price/rating missingness keep their semantics.

Rejected alternatives: fix only labels; trust mutually consistent caller flags;
accept any KNOWN field; hide mismatches as quality penalties; filter alternatives
to obtain a recommendation; trust a hash without verifying the transformation;
infer units from internal rooms or turn tariff-adult pricing into adult guests.

The report `docs/engine-v3/d0051-r1-requirements-integrity.md`, compact synthetic
before/after evidence and expanded tests identify exact rules and limits. Isolated
targeted/canonical gates, final-tree integrity and seven excluded/seventeen sealed
hashes precede selective commit/push. Final SHA and remote observations are reported
in delivery evidence, not inferred from this pre-commit decision. No main change,
public ranking/weights/roles, real decision, custody or Golden admission.

This prospectively supersedes only D-0051's insufficient guards and runtime
versions. Any rollback must be a separately authorized forward change, never
rewriting historical evidence, commits or private session bindings.
