Approved by Mattia's D-0050 instruction, 2026-09-10. Source
`6056f31fee26df468dac8d8d81b37a889afec77c`; work branch only.

Reuse the already-confirmed transcription and D-0041 preparation without new
review, mutation or feedback leakage. Add a pure evaluation pre-adapter that
retains all observed/unknown values, explicit query context, field-level evidence
and selected-rate identity. Keep original scenario, post-observation variants,
feedback labels and engine output separate. Integrity is not execution eligibility.

The current selected-location distance policy cannot faithfully consume an
unverified source-centre reference. Required boolean bookability cannot represent
unknown public availability; children count does not represent exact ages or
mandatory sleeping places. Preserve these obligations instead of inventing
coordinates, true/false verification or hard-constraint satisfaction. Missing
complete price prevents recommendation, while missing rating scale can be omitted
with reduced evidence; neither is a universal parser failure.

The real diagnostic engine is not invoked when faithful construction is blocked.
An unexecuted case is neither abstention nor agreement with human feedback.
Best Choice-only coverage is distinct from the unmapped over-budget human role.
No tolerance, Upgrade authorization, statistical case duplication, public policy
or Golden admission is inferred.

Rejected: passing transcription critical flags off as measured engine errors;
zero coordinates; treating observation as verified availability; selecting a
feedback winner; borrowing another rate's cancellation; setting bookable false
only to manufacture a conservative output. No existing decision is overwritten.

Implementation and focused synthetic/actual-contract tests are documented in
`docs/engine-v3/d0050-reviewed-intent-input-boundary.md`. Final clean-checkout gates,
source preservation, exact publication scope and local/remote synchronization
are recorded in delivery evidence. Private reports and data are never published.
No automated reversal or migration; any later boundary change requires explicit
scope and regression proof. Seven excluded and seventeen sealed files preserved.
